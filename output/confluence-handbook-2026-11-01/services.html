Package discipline

  • Commit service changes in their owning repository and update the parent submodule pin after review.
  • Use package scripts and service-local configuration. Registry-based pipeline dependencies use exact package versions; inspect current manifests rather than relying on an old README.
  • XDS/marketplace packaging guidance has evolved; validate the consumer manifest, exported artifact and CI install path together.
  • Do not include tokens, .env contents, private evidence or local database dumps in published documentation.
